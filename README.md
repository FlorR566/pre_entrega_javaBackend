# Pre Entrega Java

Proyecto desarrollado para la cursada de **Backend Java - Talento Tech**. Esta aplicación está orientada a implementar la lógica de negocio y estructura orientada a objetos en Java.

---

## Tecnologías Utilizadas

* **Lenguaje:** Java (Versión 17+)
* **IDE Recomendado:** IntelliJ IDEA
* **Control de Versiones:** Git / GitHub
---

## Estructura del Proyecto

El código fuente está organizado en los siguientes paquetes principales:

```text
src/
├── exception/    # Excepciones personalizadas para el manejo de errores
├── model/        # Entidades y modelos de datos
├── service/      # Lógica de negocio y servicios
├── ui/           # Interfaz de usuario (consola o menú)
└── util/         # Clases de utilidad y helpers
```
